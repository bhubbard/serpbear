SerpBear Cloudflare

Edge Rank Tracker

Open-source search engine position tracking running natively on Cloudflare Workers, D1, Queues, and Cron Triggers.

Available APIs

GET /healthz - Service Health Check
GET /api/domains - List Tracked Domains
POST /api/domains - Add New Domain
GET /api/keywords?domain=example.com - List Keywords
POST /api/keywords - Add Keywords to Domain
POST /api/refresh?domain=example.com - Enqueue Scrape Batch
GET /api/settings - Read Scraper & App Settings
POST /api/settings - Update Settings
GET /api/cron - Manual Cron Dispatch
